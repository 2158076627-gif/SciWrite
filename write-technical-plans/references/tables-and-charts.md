# 图表选择与三线表标记

全部内容表格采用本技能默认的三线表格式；根据内容调整字段、列宽和比较结构。具体字号、线宽和留白读取 `assets/style.json`，保留原字体、黑色文字、正文两字符首行缩进与页面规范。

## 选择方式

| 内容任务 | 优先形式 | 使用要点 |
|---|---|---|
| 设备、软件、接口、采集字段、预算、实施任务 | 三线表 `three_line` | 短字段窄、解释字段宽；型号、条件、单位和来源明确 |
| 实验指标、论文数据、定量结果 | 三线表 `three_line` | 顶线、表头下线、底线；单位写入表头，比较条件和来源明确 |
| 方法×工况、传感器×功能、消融组×模块、职责分配 | 采用矩阵结构的三线表 | 行列各代表一个比较维度；定义符号，使用文字及对齐表达分组 |
| 阶段、时间、交付物与进入条件 | 三线表，必要时另配甘特图 | 表内写明起止时间和阶段产物；甘特图作为独立图片，不在表内画网格或进度色块 |
| 技术路线、处理顺序、反馈、异常分支 | 流程图或系统框图 | 输入、处理、输出、反馈与退出条件可辨；图后解释核心依赖 |
| 方法机理、实验平台、过程、文献对照结果 | 真实期刊原图 | 按重点模块优先安排2–3张互补原图，遵循 literature-figures.md |
| 设备尺寸、结构、接口、标定、性能曲线 | 官方设备数据手册或技术手册原图 | 型号、文件版本、图号、页码和参数条件可追溯；正文映射到设备选型或实施步骤 |
| 类别比较、趋势、分布、变量关系 | 柱状图、折线图、箱线图、散点图等 | 只用可追溯数据；注明样本单位、轴和误差含义 |

避免以虚构提升比例、任意雷达评分、无来源折线制造效果。还没有实验数据时，用平台示意、技术路线或指标定义表；需要展示未来结果形式时明确标为示意，不能写成实测成绩。文献数据、本项目实测和规划目标各自标注。

三线表仅保留顶线、完整表头下线和底线，采用白底黑字，不使用外侧竖线、单元格网格、灰色表头或交替行底色。多行表头在最后一个表头行下画分隔线，跨页时重复整个表头。无表头表仅保留顶线和底线；不要为凑三条线添加空白表头。表格边界与字段组织通过列宽、留白、文字和对齐表达。

## 新建及转换 Word 表格

在构建文档时标记表头行数，再运行统一排版脚本。标记不出现在正文。

```python
import sys
from pathlib import Path
from docx import Document

skill_dir = Path("<本技能目录>")
sys.path.insert(0, str(skill_dir / "scripts"))
from apply_style import mark_table

doc = Document()
table = doc.add_table(rows=3, cols=3)
table.cell(0, 0).text = "设备"
table.cell(0, 1).text = "用途"
table.cell(0, 2).text = "验收条件"
# 继续填写正文单元格、设定列宽和对齐。
mark_table(table, "three_line", header_rows=1)
doc.save("draft.docx")
```

`mark_table` 接受 python-docx 的 Table 或 `w:tbl` XML。内容表格统一传 `three_line`；无表头传 `header_rows=0`，多行表头传实际行数。数字、日期和短状态通常居中，解释文字左对齐。采用矩阵结构时仍标记为 `three_line`。

当前默认配置设置 `default_style="three_line"` 和 `force_content_three_line=true`。脚本将未标记表、Table Grid、其他命名表格样式和旧 `grid`、`matrix`、`schedule`、`preserve` 标记转换为三线表，同时清除旧竖线、内部网格和底色。保留文字、图片、字段、列宽、合并结构及标记的表头行数；未标记表已有连续重复表头时沿用其行数，否则使用默认值。转换前核对表头，转换后检查合并单元格和跨页效果。

旧进度表或矩阵若仅靠填色表达时间、状态或分类，先把含义写成起止时间、状态文字或符号，必要时另绘甘特图，再清除填色；排版转换不能丢失原表承载的信息。

`plain` 仅用于没有正文文字的必要并排图片布局，传 `header_rows=0`，图注写在布局表外；脚本验证该布局包含图片且没有正文文字，否则转换为三线表。普通说明采用正文，不能用无框表装段落。

为兼容旧文档，接口仍接受 `grid`、`matrix`、`schedule`、`preserve` 和相应 `PlanGrid` 等样式 ID，但当前默认配置不以这些标记保留混合表格格式。只有用户明确要求本次不同样式时，才复制临时配置并关闭 `force_content_three_line`，设置 `default_style` 或逐表标记；不要为图表选择自行关闭该规则。

## 自绘图与进度图

用可复核绘图工具制作准确的流程图、系统框图、甘特图与统计图；保留可编辑源文件或绘图代码。绘制前列清节点、数据、时间、单位和来源。布局控制在正常页宽内，长标签用换行或拆图解决。

新绘图的中文、英文及数字遵循配置字体，统一黑色文字，使用克制的灰度或少量可辨识配色；线型、形状或文字同时表达区分。原论文和官方资料原图保留原文字、配色、比例、单位和色标。

正文先交代读者应从图中看到什么，再在相应位置放图；图后按图号及子图解释观察、本项目借鉴和适用边界，不能仅靠图注交代内容。图题置下，表题置上；分别采用 `PlanFigureCaption`、`PlanTableCaption` 并继承 Word Caption。题注不作正文缩进，仅含图片的段落居中，正文解读保留两字符缩进。使用题注编号和交叉引用，编辑后更新并核对。

## 验收

渲染后逐页检查全部内容表格白底三线、无竖线和内部网格，顶线与底线完整、表头下线位置正确；表头可跨页重复，多行表头与合并结构完整；列宽、换行和单位可读。逐图检查对应段落引用和解读、来源、题注相邻、标签清晰、不变形及无异常留白。配图与三线表服务于正文论证，不替代必要解释。
