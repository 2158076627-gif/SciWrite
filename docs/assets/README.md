# 展示素材

`hero.svg` 与 `workflow.svg` 为本仓库的原创介绍图；同名 PNG 是它们的光栅版本。封面中的页面图形是装饰示意，文稿的真实页面见 `previews/`。

`social-preview.png` 为 1280 × 640 像素的分享预览图，可在 GitHub 仓库 Settings → Social preview 中上传。设置步骤见 [发布指南](../publishing.md)。

`previews/research-plan.png` 与 `previews/progress-report.png` 使用对应 Word 导出的真实页面生成，供 README 展示。完整文件与来源信息见 [示例索引](../../examples/README.md)。
