# 科研项目书与计划书撰写 · 分享版

版本：1.0.0　整理日期：2026-10-11

## 可以直接转发的介绍

「科研项目书与计划书撰写」是一套面向科研写作的 AI 技能，可辅助科研项目计划书、研究方案、论文综述和技术路线的起草与修改。它从研究问题和证据入手，梳理方法、实施步骤与验证设计，通过删减套话、解释研究取舍和补足因果关系，减少模板化表达，让文字更自然、具体。技能要求核验文献与数据来源，采用三线表，按需插入真实期刊或官方设备资料图片，并在相邻正文解读，帮助形成结构清楚、便于继续修改的科研文稿。

## 主要用途

- 科研项目计划书：梳理问题、目标、方法、资源、阶段产物与验收条件。
- 研究方案：说明假设、方法依据、实验或实施设计、对照与调整条件。
- 论文综述与研究现状：按问题或机制组织文献，比较方法差异、证据边界与研究空缺。
- 技术路线：连接输入、方法、输出、依赖与验证，配合正文说明路线选择。
- 已有稿件修改：保留有效观点和专业术语，压缩重复与空泛表述，完善论证及图表。

“减少 AI 生成痕迹”在这里指减少套话、机械结构和缺乏依据的表述，使学术行文更自然、具体；不承诺任何检测分数。研究判断、引文和最终稿仍需作者核查。

## 保留的写作与排版规则

Word 默认宋体正文12磅、黑体标题、英文和数字 Times New Roman，正文1.35倍行距、首行缩进两字符。所有内容表格为白底黑字三线表，不用竖线、网格或灰色表头。各参数可以在 `assets/style.json` 中调整。

重点研究模块优先安排2–3张相关且互补的真实期刊原图，以本领域顶刊或高水平期刊为优先来源；设备选型和接口内容可补充官方数据手册图片。正文在相邻位置按图号解释图中内容、本研究借鉴及适用边界。相关性、来源核验和复用依据优先于数量，不用 AI 生成图冒充文献原图。

本包包含通用写作指引、排版配置、图表规则和 Word 排版脚本；不包含个人项目样稿、报告、论文图片或字体。文献与图片按每个研究主题另行取得，来源和使用条件由使用者核实。

## 安装：Codex CLI / IDE 本地技能

1. 解压本包，找到里面的 `write-technical-plans` 文件夹。复制这个文件夹，保留其名称和内部结构。
2. 放到下面一种位置。全局安装适用于个人各项目；项目安装适用于该项目。

| 方式 | 解压后应能找到的文件 |
|---|---|
| macOS / Linux 全局 | `~/.agents/skills/write-technical-plans/SKILL.md` |
| Windows 全局 | `%USERPROFILE%\.agents\skills\write-technical-plans\SKILL.md` |
| 项目内 | `<项目目录>/.agents/skills/write-technical-plans/SKILL.md` |

3. 在 Codex 中用 `/skills` 查看，或在输入中调用 `$write-technical-plans`。未出现时重启客户端。若已装同名技能，先备份旧版本，再更新该目录，避免重复安装。

本包采用标准 skill 目录结构。支持个人技能创建的其他环境可以读取其中的 `SKILL.md` 及完整资源目录，按该环境的安装方式导入。安装后的显示名称为“科研项目书与计划书撰写”；支持技能选择的 ChatGPT 客户端可用 `@` 选择它。

本地目录与调用方式按 OpenAI 官方文档于2026-10-11核对：[Build skills](https://learn.chatgpt.com/docs/build-skills)。具体可用入口以使用的客户端为准。

## 调用示例

### 项目计划书

```text
$write-technical-plans
根据附件资料撰写〔研究主题〕的科研项目计划书，说明研究问题、路线选择、实施步骤、阶段产物和验证条件。采用三线表，输出可编辑 Word。
```

### 论文综述

```text
$write-technical-plans
为〔研究主题〕整理论文综述。按关键问题与方法分支组织，核验引用，比较适用条件及研究不足，避免逐篇罗列。提供的论文不足时说明覆盖范围，不补造引文。
```

### 研究方案与技术路线

```text
$write-technical-plans
修改附件研究方案，保留我的有效观点，补足“问题—方法—验证”的关系，压缩套话，完善技术路线。重点模块优先选2–3张合适的真实期刊或官方设备原图，并在相邻正文逐图解读和注明来源。
```

### 仅统一 Word 排版

```text
$write-technical-plans
将附件 Word 按技能默认样式整理，所有内容表格改为三线表，保留文字、图片与引用。完成后渲染检查。
```

使用时优先提供研究问题、已有条件、目标读者、篇幅要求和已有文献；也可以上传原稿，让技能在已有内容上修改。

## Word 脚本依赖

纯文字写作无需安装 Python 依赖。运行统一排版脚本需要 Python 3.9+ 与 `lxml`，用代码新建 Word 另需 `python-docx`：

```bash
python -m pip install lxml python-docx
python "<技能目录>/scripts/apply_style.py" draft.docx --output final.docx
```

在 Windows 中可根据安装方式把 `python` 换成 `py`。脚本只统一格式，文稿写作、文献检索和原图取得由 AI 环境及其可用工具完成。若没有联网或渲染工具，技能应说明尚未核查或验收的部分。完整的独立制作与检查步骤见 `references/portable-docx.md`。
