# SciWrite v1.0.0

面向中文科研项目计划书、研究方案、论文综述与技术路线的科研写作技能。

本次发布提供：

- 完整的 `write-technical-plans` 技能目录、写作参考、排版配置与 Word 格式脚本。
- 中文与英文项目主页、原创封面与流程图。
- 两份机器人装配主题的真实文稿展示，包含页面预览、PDF 阅读版与原始可编辑 Word。
- 安装、调用、定制、贡献与仓库维护说明。

附件 **SciWrite.zip** 为原始 v1.0.0 技能分享包；下载后解压并完整复制 `write-technical-plans` 文件夹。安装范围和命令见 [安装指南](https://github.com/2158076627-gif/SciWrite/blob/main/docs/installation.md)。

纯文字写作无需 Python 依赖。独立 Word 格式脚本需要 Python 3.9+ 与 `lxml`；通过 Python 新建 Word 时另需 `python-docx`。文献检索、图片取得、Word 生成和渲染依赖使用环境提供相应能力。

示例用于展示文稿组织与版式。研究规划、引文和结果表述保留原稿，未经本仓库独立验证；作者仍需复核最终研究判断、来源与第三方图片复用条件。仓库尚未声明开源许可证。

查看 [项目主页与示例](https://github.com/2158076627-gif/SciWrite)。
